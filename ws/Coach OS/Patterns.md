# Patterns

## Known Patterns to Track

- Avoidance disguised as planning
- Overthinking
- Rewriting systems instead of executing
- Starting new projects instead of finishing
- Choosing easy project tasks over career leverage
- Skipping fitness when the day feels messy
- Using humor to weaken serious messages
- Waiting for motivation
- Making plans too big and then abandoning them

## Coaching Response

- Name the pattern clearly.
- Shrink the next action.
- Re-anchor to the weekly mission.
- Prefer proof over mood.
